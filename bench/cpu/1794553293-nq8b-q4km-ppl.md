## Protocol

Raw wikitext-2 test file, tokenized with the Qwen3 tokenizer; consecutive non-overlapping
windows; `--second-half` scores positions `ctx/2 .. ctx-2` of each window, the span
llama.cpp's perplexity uses; `Q8Act` head and embeddings, exact packed linears. Span 1 is the
first 2048 tokens (`--skip 0`), span 2 is tokens 2048–4095 (`--skip 2048`).

```
target/release/examples/ppl --model <file> [--pack nq8b/model.nqp] \
  --tokenizer tokenizer.json --data wiki.test.raw \
  --tokens 2048 --skip <0|2048> --ctx <64|128|512> --second-half
```

six decimals, so the harness is deterministic across the two machines.

## Per-layer reconstruction error

```
/workspace/venv/bin/python analyze_nq_layers.py \
  --source qwen3-8b-nanoquant.gguf --ref qwen3-8b-base-q8_0.gguf \
  --layers 0-35 --csv layers8b-poly-0-35.csv
```

Total squared error 1,637,933.1. By kind: up 27.1%, gate 26.4%, down 24.6%, q 12.2%,
o 7.6%, k 1.3%, v 0.7%. The largest layer is L33 at 3.19% of the total; L22–L34 are all
3.07–3.19%, so no layer or section is a lever on its own. The 0–16 subtotal (691,826.2)
matches the earlier CSV exactly, so the polyverse Q8_0 reference and the earlier reference
agree on the layers both cover.
